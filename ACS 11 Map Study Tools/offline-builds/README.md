# Africa Map Practice offline builds

## Current downloads

- [Windows x64 portable app, version 1.1.0](releases/windows/Africa-Map-Practice-Offline-1.1.0.exe). It includes the current country, geographic-feature, and water maps and runs without a separate browser or internet connection.
- [Android APK](releases/android/Africa-Map-Practice.apk). This includes the same current map set. Copy it to the phone and open it to install; Android may ask you to allow installs from the app used to open the file. Once installed, it works offline.

The APK is debug-signed and requests no Android permissions. It is suitable for sideloading onto a personal device, not for publishing to Google Play. The Windows EXE is unsigned, so Windows Smart App Control may block it.
