# Africa Map Practice offline builds

- `releases/windows/Africa-Map-Practice-Offline-1.0.0.exe` is a portable Windows x64 app. Double-click it to run; it does not need a separate browser or an internet connection.
- `releases/android/Africa-Map-Practice.apk` is a debug-signed Android APK. Copy it to the phone and open it to install. Android may ask you to allow installs from the app used to open the file. Once installed, the app works offline.

The Android APK bundles the site files and requests no Android permissions. It is suitable for sideloading onto a personal device, not for publishing to Google Play.
